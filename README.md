Verve Fitness is a modern and responsive fitness website designed to help users explore workouts, stay motivated, and maintain a healthy lifestyle. The project focuses on clean UI design, smooth user experience, and easy navigation across all devices.

🚀 Features
Responsive design (mobile, tablet, desktop)
Modern and user-friendly interface
Fitness/workout related sections
Smooth navigation
Clean and organized layout
Fast loading and lightweight structure
🛠️ Technologies Used
HTML5
CSS3
JavaScript
Bootstrap
